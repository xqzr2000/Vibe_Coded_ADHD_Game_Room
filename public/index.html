Welcome to Focus Room

Dr. Maple and Scout run on Groq's free tier. You need a free Groq API key — it takes about a minute and no card.

  1. Open console.groq.com/keys and sign in.
  2. Click Create API Key, name it “Focus Room”, and copy it (it starts with gsk_).
  3. Paste it below.

Your key is kept in this browser only and sent to this app just to make your own calls. It is never written to disk on the server. Focus Room only ever calls Groq's free models.

How to get a free Tavily key
  1. Go to app.tavily.com and sign up — no card needed.
  2. On the dashboard, copy your API key (starts with tvly-).
  3. Paste it above, click Test, then Save.

The free plan gives 1,000 credits a month. One Scout research run uses about 3 (2 searches + reading up to 3 pages), so roughly 300 runs. Without a key, Scout searches DuckDuckGo and reads pages itself — which works, but can be blocked from cloud servers like Codespaces.

Keys stay in this browser (localStorage) and are sent to this app only to make your own API calls — never written to the server's disk or logs. Don't paste keys into a Focus Room you don't control.
